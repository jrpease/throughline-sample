# Avatar

_Represents a user or entity._

A circular container that represents a person or entity — showing their image when available and falling back to initials otherwise. It comes in three sizes (sm / md / lg), can carry an optional online status dot, and binds its surface, text, and circular shape to the system's semantic tokens.

## When to use

- Represent a person or entity with an image or their initials
- Show presence with the optional online status dot

## When not to use

- Displaying a decorative or brand image — use a plain image
- As a button — wrap it in a Button or link if it must be interactive

## Do

- Provide meaningful alt text when showing a photo
- Give a sensible initials fallback for when the image is missing
- Keep initials to one or two characters

## Don't

- Don't rely on the status dot alone to convey presence — pair with text where it matters
- Don't stretch non-square images — the image is cropped to a circle
- Don't use an avatar as the only label for a person in dense UI without a name nearby

## Variants

### size

- `sm` — 32px — dense lists, comments, and inline mentions.
- `md` — 40px — default, for most rows and headers.
- `lg` — 48px — profile headers and other prominent placements.

## States

- `default` — Shows the image when a source is provided.
- `fallback` — No image — shows the initials on the muted surface instead.
- `status` — Optional online dot anchored to the bottom-right corner.

## Accessibility

- **Role:** `img (when showing a photo)`
- **Keyboard:** Not interactive on its own; if made actionable, wrap in a focusable control
- A photo needs descriptive alt text; initials are read as text
- The status dot is decorative (aria-hidden) — surface presence in text where it matters
- Sufficient contrast between initials and the muted background is token-guaranteed

## Tokens used

`color/bg/muted` · `color/text/primary` · `color/success/default` · `color/bg/canvas` · `radius/full` · `font/size/100` · `font/size/200` · `font/size/300`
