# Select Menu

_The dropdown surface that holds selectable options._

The popover surface opened from a Select trigger — a bordered, elevated panel with role="listbox" that holds a list of Select Menu Items passed as its content. It comes in three sizes (sm / md / lg) and binds its surface, border, radius, and elevation to the system's semantic tokens.

## When to use

- Present the list of options opened from a Select trigger
- Group a set of Select Menu Items into one scrollable, elevated surface

## When not to use

- A menu of actions or commands — use a Menu, not a listbox
- Free-form text entry — use an Input or Textarea

## Do

- Fill it with Select Menu Items and keep them consistently sized
- Match the menu size to the Select trigger that opens it
- Let long lists scroll rather than overflowing the surface

## Don't

- Don't mix unrelated actions into an option listbox
- Don't nest another menu surface inside a single option
- Don't hardcode its elevation or radius — they come from tokens

## Variants

### size

- `sm` — Compact — pairs with a small Select trigger.
- `md` — Default size for most menus.
- `lg` — Roomier — pairs with a large Select trigger.

## States

- `default` — Open surface holding its items; visibility is controlled by the Select.

## Accessibility

- **Role:** `listbox`
- **Keyboard:** Arrow keys move through options; Enter selects
- **Keyboard:** Escape closes the menu and returns focus to the trigger
- Carries role="listbox"; its children are role="option"
- Selection and active option are exposed via aria-selected and focus
- Opened and closed from the Select trigger, which owns the expanded state

## Tokens used

`color/bg/canvas` · `color/text/primary` · `color/border/subtle` · `radius/md` · `space/1` · `Elevation`
